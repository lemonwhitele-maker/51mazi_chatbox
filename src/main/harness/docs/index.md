# 51码字文档工具

内置帮助文档使用 `help/...` 路径，例如 `read({"path":"help/index.md"})`；不要写成 `book/help/...`。当前书籍文档可直接使用工作区提供的 `toolPath` 读取；其他书籍文档先 `read book/`，再原样使用目录返回的虚拟路径。`book/` 表示当前绑定书籍，不含书名。`knowledge/...` 等磁盘相对路径不能作为工具 `path`。修改前按需读取人物、设定、大纲、正文、速记或引用说明；分页只需 read({"cursor":"返回的短 nextCursor"})；list_files 同样支持仅传 cursor。游标绑定当前轮次，失效后用原路径重新读取。

目录或集合可传 `query` 做当前书籍内的文字检索。检索摘要、目录、只读视图和帮助文档不是正文读取证据。

书籍文档的 `read/write/edit.path`、`create.directory`、`sources` 和文档关联使用 `book/...` 地址；内置帮助的 `read.path` 使用 `help/...`。目录末尾 `/` 可省略；固定目录名不区分大小写，卷名和文件名按当前书中唯一匹配的实际名称解析。后端返回标准路径，并负责补齐来源版本、稳定 ID 和章节引用编码。盘符、反斜杠和 `..` 仍不可使用。
